# 정세현
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 정규화 로직을 짬.

**2. 오늘 무엇을 할 예정인가요?**
- 어제와 동일하게 로직을 짤 것이지만 계획과는 다르지만 최대한 빠르게 끝낼 듯. 거울에 비친 거도 키포인트가 생성되는데 그거 없애는 로직 완성 주기성 로직.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 로직을 계속 짜서 결과물이 나오도록.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 거울이나 유리창에 비친 인물에게도 키포인트가 생겨 2개의 바운딩박스가 잡히는 문제 (주기성 판정 시 오류 유발).

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 바운딩박스 크기 및 중앙 영역 가중치 기반으로 주 객체를 식별하는 필터 로직 팀원들과 공유.

# 정승인
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 인프라 POC 상황에서 전부 다 조사하고 이것에 대해서 하는 것보다 현재 정의해놓은 인프라에 대해서 검토를 하고 다른 인프라적으로 뭔가 확장할 수 있는 방법이 있는지 정리가 되었고, 정리가 되었지 선택할 수 있다고 할 수는 없다. 그걸 같이 이야기할 예정.

**2. 오늘 무엇을 할 예정인가요?**
- 현재 단일 인스턴스 기반 인프라 안정화 및 GitHub Actions 연동 배포 자동화(CI/CD) 파이프라인 검토.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 인프라 개선안 정리 문서 및 CI/CD 워크플로우 초안.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 클라우드 비용 한도 내에서 최적의 컨테이너 리소스 할당치 산정.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 조장과 이야기.

# 박재혁
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 논문 읽고 걸러야 할 것, 읽어야 할 것 정리.

**2. 오늘 무엇을 할 예정인가요?**
- 논문별 피처 매핑 최종본 검토 및 프론트엔드 UI 대시보드 와이어프레임 설계.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 피처 결과 리포트 출력 포맷(HTML/JSON) 명세서 및 와이어프레임.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 리포트 내 전문 의학/생체역학 용어를 일반 러너가 쉽게 이해할 수 있도록 표현하는 방안.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 피처별 수치 범위 및 리포트 문구 최종 리뷰.

# 유한나
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 논문 분석했는데, 양식 맞춰서 다시 함.

**2. 오늘 무엇을 할 예정인가요?**

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**

**4. 막혀 있거나 애매한 부분이 있나요?**
- 주자별 키와 보폭에 따른 각도 정상 범위의 개인차 반영 문제.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 세현님과 피처 추출 파이프라인 연동 인터페이스 최종 협의.

# 박주환
