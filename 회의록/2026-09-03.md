# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- OCI의 기존 영상 처리 구조와 Grafana 측정 기준을 확인했습니다.
- Grafana의 총 처리시간은 약 42~45초이며, 이 중 자세 추론 단계는 약 14.7~16.7초였습니다.
- RunPod에 GPU 추론 API를 구성하고 OCI에서 호출하는 데 성공했습니다.
- 동일한 136프레임 영상으로 비교한 결과:
    - OCI CPU 자세 추론: 16.737초
    - OCI→RunPod GPU 요청 전체: 5.282초
    - 약 3.17배 빨라졌습니다.
- 다만 현재는 별도 연결 테스트까지 완료한 상태이며, 기존 Celery 파이프라인에는 아직 적용하지 않았습니다.

**2. 오늘 무엇을 할 예정인가요?**
- OCI CPU 결과와 RunPod GPU 결과가 동일한 수준인지 비교합니다.
- 결과에 문제가 없으면 기존 Celery 파이프라인에서 CPU/GPU 방식을 선택할 수 있도록 연결 방안을 검토합니다.
- 실제 Grafana 작업을 다시 실행해 전체 처리시간이 얼마나 줄어드는지 측정합니다.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- CPU와 GPU 추론 결과의 정확도 비교 자료
- GPU 적용 전후의 단계별·전체 처리시간 비교표
- 기존 서비스에 GPU를 적용할 수 있는지에 대한 결론

**4. 막혀 있거나 애매한 부분이 있나요?**
- GPU 결과가 기존 CPU 결과와 동일한 품질인지 아직 확인하지 않았습니다.
- 현재 수치는 별도 API 호출 결과이므로, 실제 Grafana 전체 처리시간 단축 효과는 아직 추정치입니다.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 속도 향상을 위해 RunPod 같은 외부 GPU 서비스를 사용할 수 있는지 결정이 필요합니다.
- GPU 장애 시 OCI CPU로 대체 실행할지 정책 결정이 필요합니다.
