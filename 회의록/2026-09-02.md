# 정세현
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 오류 해결을 완료했음. 아직 해결하지 못한 오류가 2가지가 있다.
- 식물이 detection 되는 현상 > 해결 완료.
- 러닝 발목각도와 그래프 사이에 정확성이 안 맞음. 측면으로 달리기는 하는데 후방이 살짝 찍히니깐 주기성이 훼손되는 것 같다.  
  똑같은 자세임에도 각도 그래프가 다르게 나타난다는 것은 카메라 문제가 발생하지 않았나 생각이 든다. 논문은 트레드밀에서 측정한 피쳐값이지 우리 야생 영상과는 다르다.
- GCT 구간이 살짝 반대가 되어서 지면착지와 이탈이 순서가 바뀌었다. 해결 방법은 찾았지만 구현은 아직 안 함.

**2. 오늘 무엇을 할 예정인가요?**
- GCT 인덱스 반전 버그 수정 및 구간 판정 로직 구현.
- 각도 그래프 튀는 현상 방지를 위한 스플라인 보간 및 평활화 적용.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- GCT 순서 정상화된 피처 추출 스크립트 및 이상치 보정 코드.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 트레드밀 연구 논문과 야생 필드 영상 간의 운동역학적 차이 보정.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 데이터팀과 이상치 필터 로직 크로스체크.

# 정승인
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- Grafana 모니터링 시스템 연동 및 OCI VM 리소스 사용량 추적.
- 전체 파이프라인 지연 시간 프로파일링 결과, 136프레임 영상 처리에 총 44초가 소요되는 심각한 병목 발견 공유.

**2. 오늘 무엇을 할 예정인가요?**
- 44초 병목 구간 세부 분석: CPU 기반 ONNX 추론 연산이 80초 이상 소요됨을 확인하고, 이를 해결하기 위한 GPU 인스턴스 전환 가능성 검토.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 구간별 레이턴시 프로파일링 보고서 및 클라우드 GPU 인스턴스 비용/성능 비교표.

**4. 막혀 있거나 애매한 부분이 있나요?**
- OCI 무료 티어 내 GPU 자원 부재로 인한 추가 인프라 도입 필요성.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 외부 GPU 서버(RunPod 등) 임시 활용에 대한 팀 합의.

# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- Grafana 모니터링을 통해 136프레임 영상 1건 처리에 무려 44초가 걸리는 병목을 정량적으로 실측하고 충격을 받음.
- 세부 프로파일링 결과, 서버 CPU 환경에서 RTMDet 및 RTMPose 추론이 전체 시간의 대부분을 차지함을 규명.

**2. 오늘 무엇을 할 예정인가요?**
- 외부 클라우드 GPU(RunPod) 환경 구축 및 가성비 GPU(시간당 400원 수준의 RTX 2000 Ada) 세팅.
- 동일 영상(136프레임)으로 CPU vs GPU E2E 파이프라인 속도 실측 벤치마크 수행.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- RunPod GPU 벤치마크 환경 세팅 완료 및 1차 실측 비교 데이터.

**4. 막혀 있거나 애매한 부분이 있나요?**
- ONNX Runtime의 CUDA/TensorRT execution provider 종속성 및 패키지 충돌 해결.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- GPU 가속 효과 확인 시 프로덕션 적용 방식 협의.
