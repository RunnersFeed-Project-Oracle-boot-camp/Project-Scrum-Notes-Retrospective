# 정세현
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 피쳐 로직을 짰고, 추가를 하였다. Joint angle 수식을 살짝 바꿨고 깃허브에 push할 예정. 키포인트를 연결하는 관절의 각도 등을 각각 만들었다.

**2. 오늘 무엇을 할 예정인가요?**
- 팔꿈치 각도의 그래프를 그려볼까 생각 중.
- 고개 각도가 호흡과 연관이 있기 때문에 그것과 관련된 피쳐를 구하기 위해 코, 귀, 입을 연결해볼 생각.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 몸통 피쳐 오늘까지 나왔으면 하고, 팔꿈치 각도 산출.
- 논문과 피쳐 한쌍이 들어간게 아니라 피쳐가 논문에 의해서 결론이 난 상태에서 에이전트가 들어갈 생각 (에이전트가 자체 판단하지 않게 할 생각).

**4. 막혀 있거나 애매한 부분이 있나요?**
- 야생 데이터(손 촬영 스마트폰 영상)에서 카메라 흔들림으로 인한 각도 측정 노이즈.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 궁금한 거 있으면 편하게 물어봐라.

# 정승인
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 깃액션에 대해서 인프라 관점에서 어떻게 도입할지 검토.

**2. 오늘 무엇을 할 예정인가요?**
- Grafana 대시보드 및 Prometheus 연동하여 서버 CPU/메모리/네트워크 실시간 메트릭 수집 체계 구축.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- OCI 서버 성능 모니터링 Grafana 대시보드 활성화.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 모니터링 에이전트의 주기적 메트릭 수집이 시스템 리소스에 미치는 오버헤드 최소화.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 팀 슬랙 채널 웹훅 연동 권한 및 알림 조건 확인.

# 박재혁

- 백엔드 API 엔드포인트(/api/v1/analyze) 초안 구현 및 DB 스키마 마이그레이션.

**2. 오늘 무엇을 할 예정인가요?**
- 프론트엔드 비디오 업로드 컴포넌트와 백엔드 API 연동 테스트.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 영상 업로드 후 작업 ID 반환 및 상태 폴링 API 연동 확인.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 대용량 비디오 업로드 시 네트워크 타임아웃 방지 대책.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 인프라 파트와 업로드 임시 스토리지 볼륨 설정 협의.

# 유한나
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 피처별 기준치 및 논문 근거 매핑 문서 보완.

**2. 오늘 무엇을 할 예정인가요?**
- 스마트폰 손 촬영 야생 데이터셋 기반 피처 이상치 케이스 수집 및 분석.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 야생 데이터 피처 이상치 분석 리포트 및 촬영 가이드라인 보완안.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 카메라 앵글 왜곡 시 피처 각도 편차 보정 기준.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 모델링 파트와 촬영 가이드라인 필수 안내 문구 조율.

# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 스마트폰으로 직접 손 들고 촬영한 실제 '야생 데이터(In-the-wild)' 러닝 영상 테스트.
- 삼각대 고정 영상과 달리 손 떨림과 원근 왜곡으로 인해 관절 각도 시계열 분산이 급증하는 현상 확인.

**2. 오늘 무엇을 할 예정인가요?**
- 손 떨림 노이즈를 완화하기 위한 이동평균(Moving Average) 필터 적용 테스트.
- 프레임별 키포인트 신뢰도(Confidence Score) 하위 10% 데이터 제거 후 피처 안정성 평가.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 야생 데이터 노이즈 필터링 전후 분산 비교 차트 및 최소 촬영 가이드 제안서.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 과도한 필터링 시 러너의 급격한 관절 전환(착지 순간) 데이터가 뭉개지는 트레이드오프.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 프론트엔드 촬영 안내 가이드에 '삼각대 거치 또는 수평 고정 촬영 권장' 문구 반영 요청.
