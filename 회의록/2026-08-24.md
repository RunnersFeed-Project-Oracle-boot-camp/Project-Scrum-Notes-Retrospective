# 정세현
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 지난주까지 파이프라인 구축 완료, 1차 데이터셋 파이프라인을 Streamlit 활용해 화면에 띄우는 것 확인 완료.
- 모델 추출 결과 바탕으로 에이전트 연동까지 이어지는 파이프라인 구현 완료 및 PoC 1단계 마무리.

**2. 오늘 무엇을 할 예정인가요?**
- 조사된 논문 피처 리뷰하고, MVP 작성 과정 검토 예정.
- 사용자가 앱 접속 시 할 수 있는 모든 경우의 수 조사 (로그인 -> 프론트 -> 백엔드 -> 데이터/API) 및 시각화.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 논문 리뷰 결과 페이지 및 Figma 상세 화면 흐름 시각화 산출물.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 사용자의 다양한 행동 경우의 수를 코드로 처리할 때의 예외 로직 설계.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- MVP 기능 기반 Figma 사용자 흐름도 조장님(재혁님)과 싱크 맞추기.

# 정승인
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 주말 동안 노션 읽고 AI 에이전트 구조 파악.
- 우리가 설계한 인프라 기반으로 백엔드 및 프론트엔드 연동 페이지 작업 진행 중. 논문에서 단일 카메라 기반 연구 사례 탐색.

**2. 오늘 무엇을 할 예정인가요?**
- 백엔드와 프론트엔드 기초 연결 작업 마무리 및 OCI 환경 세팅 진행.
- 팀원들과 인프라 연결 상태 및 각자 맡은 모듈의 연동 방식에 대해 진지하게 이야기할 예정.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 백엔드-프론트엔드 기초 통신 확인 및 OCI 단일 서버 배포 환경 구동.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 각 파트별 작업 명세가 아직 구체적이지 않아 명확한 인터페이스 정의 필요.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 스크럼 종료 후 팀원들과 현재 진행 상황 및 인프라 구조 공유 및 일정 조율.

# 박재혁
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 기본 아키텍처 정리 및 팀원들의 작업물 검토, 앞으로의 전체 일정 조율.
- MVP 핵심 기능 정의 및 PRD 0.3 작성 준비.

**2. 오늘 무엇을 할 예정인가요?**
- MVP 스코프 상의 및 확정:
  1. 측면 뷰 우선 MVP 구현 (단기간 내 3방향은 무리이므로 측면 집중).
  2. 단일 서버 통합 구축 (멘토 조언 반영하여 서버 1대에 컨테이너 통합).
  3. LLM 리포트 생성을 위한 피처값 프롬프트(prompt.py) 연동 구조 설계.
  4. RAG 대신 피처별 확정 논문 근거 룰베이스 매핑 전략 채택.
  5. 웹사이트 메인에 피처 신뢰도/근거 설명 페이지 배치 구상.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- PRD 0.3 완성본 및 MVP 기능 명세서, Figma 와이어프레임.

**4. 막혀 있거나 애매한 부분이 있나요?**
- RAG 도입 여부에 대한 논의가 있었으나 불필요한 검색 오버헤드를 줄이고 정밀한 수식 근거를 직접 매핑하는 방식으로 정리.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 각 파트별 MVP 요구사항 전달 및 이번 주 핵심 목표 일치시키기.

# 유한나
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 주환님과 함께 피처값 로직 선정하고 JSON 파일 기반 키포인트 파생값 파이프라인 구축하여 모델링 파트에 전달.
- 선행 연구 논문 분석 진행.

**2. 오늘 무엇을 할 예정인가요?**
- 타깃 논문(5km 22분 이상 러너 대상) 외에 일반 러너에게도 적용 가능한 일반화 논문 추가 서칭.
- 피처 카테고리별 및 달리는 속도별 데이터 분류 체계 정립.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 논문 속성 기반 피처 매핑 데이터 및 속도별 분류 체계 정리 문서.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 피처마다 이상적 기준치의 대상(속도, 숙련도)이 달라 일반화 기준점 도출이 까다로움.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 주환님과 함께 선별된 대상 논문의 수치들을 대조하고 타당성 검토.

# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 밀렸던 피처 선정 완료 (5가지 카테고리별 피처).
- 작성한 피처 기반 파이썬 로직 구현 진행 (B 카테고리까지 완성, 각 지표 조건별 피드백 로직 구현 완료).

**2. 오늘 무엇을 할 예정인가요?**
- 피처 계산 로직 정리 후 깔끔하게 py 파일로 모듈화하여 세현님에게 전달.
- 노션 테이블 정리 및 개인 깃허브 정리. 이번 주 결과물 완성을 위한 작업 집중.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 2D 프록시 피처 산출 파이썬 모듈(py) 완성본 및 모델링 파트 전달 완료.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 3D 모션캡처 논문 수치를 2D 단안 영상 좌표에 적용할 때 생기는 프록시 오차(±5° 허용치)의 통계적 정합성 입증.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 피처 계산 모듈과 모델 파이프라인 간의 입출력 데이터 규격 및 예외 처리 기준 합의.
