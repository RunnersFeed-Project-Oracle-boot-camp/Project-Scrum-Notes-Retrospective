# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- RunPod GPU 1차 벤치마크 완료 (136프레임 기준 CPU 124초 -> GPU 10초로 약 12.4배 단축 입증).
- GPU로 추론 시간을 크게 줄였으나, 136프레임 이미지 입출력(I/O, 약 8.8초)이 새로운 병목으로 파악됨.
- JPEG vs PNG 속도 차이 샘플 분석 및 이미지 출력 비교 (PNG 대신 JPEG q95 저장 시 I/O 가속 효과 확인).

**2. 오늘 무엇을 할 예정인가요?**
- JPEG 손실 압축 적용 시 2D 키포인트 좌표 오차와 핵심 러닝 피처(무릎 각도, 몸통 기울기 등)에 미치는 영향 분석.
- 29장 균등 추출을 통한 [Phase 1] 예비 검증 파이프라인 스크립트 작성 및 오차 분포 측정.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- PNG vs JPEG(q95) 29장 예비 검증 결과 보고서 및 오차 비교 차트.
- 주말 동안 진행할 255프레임 전수 검증 파이프라인 설계안.

**4. 막혀 있거나 애매한 부분이 있나요?**
- JPEG 손실 압축으로 인한 미세한 좌표 차이가 실제 러닝 피드백 판정에 미치는 영향(허용 한계) 정의.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 모델링/프론트 팀에서 각도 오차 0.5° 미만일 경우 사용자 피드백에 문제가 없는 것으로 합의 가능한지 확인.
