# 정세현
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- Streamlit을 활용해 1차 PoC 파이프라인(영상 업로드 -> 키포인트 추출) 웹 화면 프로토타입 구현 완료.

**2. 오늘 무엇을 할 예정인가요?**
- 오라클 강사님 멘토링 피드백 청취 및 반영.
- PoC 구조를 단일 서버 서빙 아키텍처에 맞게 리팩토링 준비.
- 논문 피처 로직을 연결하기 위한 JSON 좌표 데이터 구조 표준화.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- Streamlit PoC 개선 버전 및 키포인트 시계열 JSON 출력 모듈.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 영상 분석 완료 후 LLM 리포트 생성까지의 비동기 처리 흐름 연결.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 백엔드와 주고받을 JSON 데이터 스키마 최종 확정.

# 정승인
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- OCI 인스턴스 구성안 검토 및 Figma 아키텍처 다이어그램 작성 시도.
- 오라클 교육 강사님께 인프라 구성 멘토링 진행.

**2. 오늘 무엇을 할 예정인가요?**
- 강사님 조언 반영: 초기부터 서버 여러 대로 분산하지 않고, OCI VM 인스턴스 1대에 Docker로 프론트엔드, 백엔드(FastAPI), DB(PostgreSQL)를 통합 구축하는 단순화 전략 수립.
- OCI 오브젝트 스토리지 연동 및 파일 업로드 파이프라인 설계.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 단순화된 OCI 단일 인스턴스 아키텍처 설계안 및 Docker Compose 구성 계획.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 영상 분석 모델을 비동기 워커로 분리할 때 FastAPI 백그라운드 태스크 vs Celery/Redis 도입 기준.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 인프라 리소스 한계에 따른 모델 동시 요청 처리 정책 협의.

# 박재혁
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 팀 아키텍처 구조 정리 및 오라클 멘토링 참석.
- 프론트엔드 프레임워크(Next.js vs Vite React) 및 백엔드(FastAPI) 기술 스택 검토.

**2. 오늘 무엇을 할 예정인가요?**
- 멘토 피드백을 반영하여 PRD 0.3 수정 (0.1 버전은 서버 1대에 통합 배포 후 점진적 분리).
- LLM 기반 피드백 리포트 생성을 위한 프롬프트 엔지니어링 구조 설계.
- RAG 대신 확정된 피처-논문 근거 룰베이스 매핑 전략 확정.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 수정된 PRD 0.3 및 프롬프트 템플릿 구조안.

**4. 막혀 있거나 애매한 부분이 있나요?**
- LLM 출력의 신뢰성(할루시네이션 방지)을 위한 엄격한 수치 기반 프롬프트 튜닝.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 주환님과 한나님이 정리한 피처별 근거 논문 데이터 취합.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**

# 박주환
**1. 어제부터 지금까지 뭐가 진행됐나요?**
- 피처 수치 기준의 통계적 정합성 검토 및 설문조사 결과 팀 내 공유.
- 오라클 본사 방문 멘토링 참석 및 인프라 구조 청취.

**2. 오늘 무엇을 할 예정인가요?**
- 논문에서 도출된 피처별 정상치/이상치 기준을 PostgreSQL DB에 적재할 테이블 스키마 설계.
- 2D 평면에서 삼각함수(atan2)를 이용해 관절 각도를 오차 없이 계산하는 파이썬 수학 함수 초안 작성.

**3. 오늘 끝날 때 어떤 결과물이 나오면 되나요?**
- 피처 기준치 데이터베이스 테이블 스키마 초안 및 관절 각도 계산 수학 함수 스크립트.

**4. 막혀 있거나 애매한 부분이 있나요?**
- 3D 모션캡처의 해부학적 랜드마크(C7 경추, 골반 중심 등)를 2D Halpe-26 키포인트로 대체할 때의 기하학적 오차 보정.

**5. 팀에서 도와주거나 결정해줘야 할 게 있나요?**
- 모델링 파트에서 출력해주는 2D 키포인트 신뢰도(score) 필터링 임계값(예: score > 0.3) 협의.
