# [2026-09-03] 일일 회고: 400원의 기적 (12.4배 GPU 가속 성공과 신규 I/O 병목 발견)

## 1. 📝 오늘 진행한 일 (Fact)
- RunPod에서 시간당 400원짜리 NVIDIA RTX 2000 Ada 인스턴스 환경 구축 (PyTorch CUDA 12.8, ONNX Runtime GPU 1.26.0)
- RTMDet 및 RTMPose-M Halpe26 ONNX 모델의 GPU 세션 로드 성공
- 720p 136프레임 실제 영상으로 동일 조건 CPU vs GPU 실측 비교 수행
  * 모델 순수 연산: CPU 83.52초 ➔ GPU 2.24초 (**37.3배 가속**)
  * 전체 HPE 프로그램: CPU 124.39초 ➔ GPU 9.996초 (**12.44배 가속, 1분 54초(92%) 단축**)

## 2. 💡 배운 점 및 문제 해결 (Finding & Troubleshooting)
- GPU로 모델 연산은 2.2초로 엄청나게 빨라졌으나, 앞단에서 136장 프레임을 디스크에 PNG로 쓰고 읽는 시간(8.84초)이 그대로 남아 새로운 병목이 됨을 발견
- 모델이 빨라지니 파일 I/O와 이미지 인코딩이 전체 지연의 80% 이상을 차지하는 '병목 역전(Bottleneck Shift)' 현상 확인 (파레토 법칙)

## 3. 💭 솔직한 소회 및 느낀 점 (Feeling)
터미널에 `real 9.996s`가 찍히는 순간 육성으로 환호했다.
고작 몇백 원의 비용으로 서비스 전체의 핵심 병목을 해결할 확실한 근거를 내 손으로 만들었다.
"나도 비전공자이지만 팀에 실질적이고 강력한 기여를 할 수 있구나!"라는 확신이 들었다.

## 4. 🎯 향후 계획 및 다짐 (Future Action)
- 8.8초의 프레임 I/O 병목을 해결하기 위해 PNG 대신 JPEG(품질 95) 적용 가능성 검토
- 손실 압축이 관절 좌표 정확도에 미치는 영향 예비 검증 (Phase 1 표본 검증 설계)
