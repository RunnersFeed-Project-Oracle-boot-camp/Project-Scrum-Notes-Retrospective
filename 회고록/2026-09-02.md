# [2026-09-02] 일일 회고: Grafana 44초 병목의 충격과 RunPod GPU 도입 결심

## 1. 📝 오늘 진행한 일 (Fact)
- OCI 서버에서 돌아가는 전체 파이프라인의 처리 시간을 Grafana 모니터링으로 정밀 측정
  * 총 처리시간: 약 42~45초 소요 (영상 다운로드/프레임 추출 8~9초, 자세 추론 15~17초, 렌더링 12~14초, 리포트 생성 5~7초)
- RTMDet 사람 감지와 RTMPose 자세 추정 모델의 CPU 연산 병목 분석
- 외부 클라우드 GPU(RunPod)를 통한 추론 가속 가능성 사전 조사 및 환경 테스트 준비

## 2. 💡 배운 점 및 문제 해결 (Finding & Troubleshooting)
- 짧은 러닝 영상 하나에 45초가 걸린다면 실서비스는 물론 최종 데모 시연도 불가능함
- 전체 지연의 대부분이 CPU 환경에서의 ONNX 딥러닝 추론에서 발생함을 정량적으로 규명하고, 시간당 400원 수준의 가성비 GPU 인스턴스(RTX 2000 Ada) 도입을 주도적으로 결정

## 3. 💭 솔직한 소회 및 느낀 점 (Feeling)
Grafana의 44초 수치를 보고 큰 충격을 받았다.
"비전공자니까 인프라는 몰라" 하고 넘길 수도 있었지만, 데이터로 원인을 밝혔으니 내가 직접 해결사로 나서기로 결심했다.
처음 해보는 GPU 서버 세팅이지만, 팀원들의 짐을 덜고 서비스를 살리기 위해 반드시 성공시키겠다.

## 4. 🎯 향후 계획 및 다짐 (Future Action)
- RunPod에서 RTX 2000 Ada 인스턴스를 대여하고 CUDA/ONNX Runtime GPU 환경 구축
- 동일 영상으로 CPU vs GPU 추론 성능 실측 비교 수행
