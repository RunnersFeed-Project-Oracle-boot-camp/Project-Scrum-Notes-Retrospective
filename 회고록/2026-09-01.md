# [2026-09-01] 일일 회고: 스마트폰 손 촬영의 야생 데이터와 전처리의 필요성

## 1. 📝 오늘 진행한 일 (Fact)
- 모델링 결과물과 실제 러닝 영상의 키포인트 트래킹 데이터 분석
- 손으로 스마트폰을 들고 촬영한 영상에서 발생하는 흔들림과 각도 왜곡 현상 확인
- OCI 서버 구조와 Docker 컨테이너 흐름을 정리한 문서(배포 아키텍처 흐름도) 학습

## 2. 💡 배운 점 및 문제 해결 (Finding & Troubleshooting)
- 논문은 트레드밀 위에서 고정된 초고속 카메라로 촬영한 것이지만, 현실 서비스는 손떨림과 시점 이동이 심한 야생 데이터(In-the-wild)임
- 완벽한 수식이라도 입력 영상의 흔들림 보정과 이상치 필터링이 없으면 각도 시계열 데이터의 분산(Variance)이 치솟아 이상 판정이 남발됨을 발견
- 맥북 -> 깃허브 -> OCI 서버 -> 도커 컨테이너 -> Celery 워커로 이어지는 배포 흐름을 이해함

## 3. 💭 솔직한 소회 및 느낀 점 (Feeling)
논문 속 수식만 맞추면 끝나는 줄 알았는데 현실 데이터는 훨씬 가혹했다.
하지만 문제를 발견했으니 해결할 방법도 찾을 수 있다. 모르면 배우고 안 되면 찾아보면서 나아가는 중이다.
